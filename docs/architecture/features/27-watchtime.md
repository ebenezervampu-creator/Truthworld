# Feature 27: Watch Time

## Overview
The **Watch Time** feature is a specialized analytics and digital wellbeing module. It tracks the aggregate duration a user spends consuming content on the platform.

## Frontend (UI/UX)
- **Location**: `lib/features/watchtime/presentation/pages/`
- **Pages**:
  - `watchtime_details_page.dart`: Renders visualizations (like bar charts) of the user's daily and weekly consumption habits. It often includes digital wellbeing controls, allowing users to set "Take a break" reminders.

## Backend Architecture
- **Data Flow**: Relies on a combination of local device state tracking and remote aggregations (often powered by a dedicated `watchtime` Cloud Function). It aggregates the raw `watch_session` chunks generated by the video player into daily totals for reporting.
