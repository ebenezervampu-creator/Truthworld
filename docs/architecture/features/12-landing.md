# Feature 12: Landing

## Overview
The **Landing** feature acts as the unauthenticated entry gate for TruthWorld. It is designed to provide marketing copy, showcase platform features, and drive user acquisition/sign-ups.

## Architecture
- **Location**: `lib/features/landing/presentation/`
- **Current State**: This directory currently serves as an architectural placeholder or shell. It contains the standard `presentation/views` and `presentation/widgets` directories, designed to hold high-performance static marketing assets and authentication entry point buttons.
- **Future Integration**: Intended to be expanded into a fully responsive splash/landing website decoupled from the heavy video playback logic to ensure ultra-fast first-contentful-paint (FCP) metrics.
